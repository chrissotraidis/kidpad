# Security policy

## Supported versions

Only the latest commit on `main` is actively maintained. Development builds
may contain unfinished features and should not be used with sensitive data.

## Reporting a vulnerability

Please do not include secrets, private documents, or exploit details in a
public issue. Use GitHub’s private vulnerability reporting feature for this
repository when available. If it is not enabled, contact the maintainer
through their GitHub profile and request a private channel before sharing
details.

Include the affected commit or build profile, device/runtime, reproduction
steps, impact, and any suggested mitigation. Allow reasonable time for review
before public disclosure.

## Scope

Security reports may cover the native iPad app, document persistence, file
import/export, build scripts, and repository automation. Licensing or asset
provenance concerns should be raised privately when they could expose material
that should not be redistributed; see
[`RIGHTS_AND_LICENSES.md`](RIGHTS_AND_LICENSES.md).
