# FidelityDev assets

This ignored directory is an optional private cache of files from the pinned
`vikrum/kidpix@99c67f3427d229f7db60b03dcf19df4d8c2a8ecf` source. No PNG or WAV
from this directory is tracked or bundled in KidPad.

Populate them locally:

```bash
Scripts/sync_fidelity_assets.sh
```

The app itself downloads the same pinned Classic Pack directly from JSKidPix
after the user agrees on first launch. This local cache is only for private
fidelity tests. Never commit its contents.
