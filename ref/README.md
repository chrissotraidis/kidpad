# Reference workspace

Historical and third-party material belongs here only when lawfully acquired.
Unverified reference files are ignored and must not enter the public source
tree or application bundle.

The local `source-jskidpix` checkout pins the behavior and Classic Pack source
used during engineering comparison. Private screenshots and visual references
may also be stored under this directory. Only this README, lock metadata, and
synthetic input traces are intended for public tracking.

Runtime Classic Pack data comes directly from the pinned upstream JSKidPix
revision after user consent. See [`RIGHTS_AND_LICENSES.md`](../RIGHTS_AND_LICENSES.md)
and [`AssetLedger.json`](../AssetLedger.json) for the public distribution
boundary.
